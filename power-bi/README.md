# Power BI Dashboard

This folder documents the Power BI analytics layer of the Payment Analytics Platform.

## Report pages

- Executive Overview
- Merchant & Channel Performance
- Customer & Card Insights
- Fraud & Operational Performance
- Payment Channel Detail

## Features

- Reusable DAX measures
- Synced slicers and reset-filter bookmarks
- Report-page tooltips
- Payment-channel drill-through
- Conditional formatting and risk heatmaps
- Current-year versus previous-year comparisons

## Dashboard download

The complete `.pbix` file is available under the GitHub Release tagged `power-bi-v1.0.0`.
