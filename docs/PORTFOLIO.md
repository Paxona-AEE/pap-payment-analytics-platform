## LinkedIn project description — English

Built a Microsoft SQL Server payment analytics data warehouse using a star schema and one million synthetic transactions. The project includes deterministic data generation, staged incremental ETL, data-quality validation, reject handling, batch/run logging, load lineage, analytical views, parameterized stored procedures, window functions, covering and columnstore indexes, an indexed view, and role-based database security. I deliberately kept the dimensions non-historized to focus the project on payment analytics, operational ETL, and query performance.
